## Como visualizar um diagrama

1. Baixe o arquivo `.drawio`.
2. Acesse [diagrams.net](https://app.diagrams.net/).
3. Selecione **File → Open From → Device**.
4. Escolha o arquivo baixado.

O GitHub pode mostrar o XML do arquivo ao abri-lo no navegador. Isso é normal; para ver o diagrama, abra-o no Draw.io.
